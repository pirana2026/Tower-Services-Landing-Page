RESEARCH & ORCHESTRATION

STACD Overview

SpatioTemporal Asset Catalog with DAGs · IIT Delhi Research

What is STACD?

Geospatial datasets have complex lineages that are crucial for reproducibility and understanding data provenance, yet current metadata standards like STAC (SpatioTemporal Asset Catalog) provide limited support for capturing complete processing workflows. We propose STACD (STAC extension with DAGs), an extension to STAC specifications that incorporates Directed Acyclic Graph (DAG) representations along with defining algorithms and version changes in the workflows. We also provide a reference implementation on Apache Airflow to demonstrate STACD capabilities such as selective recomputation when some datasets or algorithms in a DAG are updated, complete lineage construction for a dataset, and opportunities for improved collaboration and distributed processing that arise with this standard.

Key Features

  • Selective Recomputation: When an algorithm is updated, STACD re-runs only the affected steps instead of processing the entire workflow again.
  • Automated Workflows: Developers define pipelines using simple YAML configurations, which automatically compile into executable Apache Airflow DAGs.
  • Full Data Provenance: Tracks dataset versions and history across multiple computational tools and isolated Docker containers.

Real-World Impact

STACD serves as the data orchestration backbone for the CoRE Stack project at IIT Delhi, powering drone canopy processing, bioacoustics monitoring, and landscape mapping across more than 1,000 villages in India.

MORE ABOUT US

CoRE Stack

Establishing a Collaboration Network on Commoning Technologies for Resilience and Equality.

CoRE Stack is an open initiative dedicated to empowering communities and researchers with spatial data tools for sustainable land and natural resource management. CoRE Stack is a digital public good that helps communities manage landscapes and natural resources sustainably. It promotes community participation, scientific decision-making, resilience, and equality. It uses responsible AI, ethical practices, and open-source tools for transparency and accountability. The platform is developed and managed by CommonsTech Foundation for climate action and sustainable development.
